# Auriel Consultancy Website

A modern, responsive website for Auriel Consultancy, designed to showcase professional consulting services, business solutions, and project experience.

The website provides visitors with information about the business, its services, portfolio, team, and contact details through a clean and professional interface.

## Features

- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **About Section:** Introduces the consultancy and its approach.
- **Services:** Showcases business consulting, strategic planning, project management, market research, business analysis, and operational support.
- **Portfolio:** Displays selected projects and professional work.
- **Team:** Presents team members and their areas of expertise.
- **Testimonials:** Provides a section for client feedback.
- **Pricing:** Presents available service packages.
- **FAQ:** Answers common questions about the consultancy.
- **Contact Form:** Allows visitors to submit inquiries.
- **Social Media Integration:** Provides links to social media profiles.
- **Custom Branding:** Incorporates branded images, backgrounds, logos, and a favicon.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons
- AOS (Animate On Scroll)
